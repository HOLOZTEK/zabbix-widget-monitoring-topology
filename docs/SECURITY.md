# Security Policy

## Supported Versions

Security fixes are prepared for the latest published version of Monitoring Topology.

## Reporting a Vulnerability

Do not disclose suspected vulnerabilities in a public issue before maintainers have assessed them.

Report them privately through GitHub private vulnerability reporting:

https://github.com/HOLOZTEK/zabbix-widget-monitoring-topology/security/advisories/new

Include the affected widget, Zabbix, and PHP versions; reproduction steps; expected impact; and relevant logs or screenshots with secrets and infrastructure identifiers removed.
